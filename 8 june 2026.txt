db.students.find({
    dept: "CS",
    marks: { $gt: 80 }
})

Output:

{ _id: 1, name: "Ananya", dept: "CS", marks: 88, ... }
{ _id: 3, name: "Meena",  dept: "CS", marks: 95, ... }

4. Find students NOT in the CS department using $nin and project only name and dept
db.students.find(
   { dept: { $nin: ["CS"] } },
   { _id: 0, name: 1, dept: 1 }
)
Output
{ name: "Arjun", dept: "IT" }
{ name: "Ravi", dept: "ECE" }
{ name: "Kavya", dept: "IT" }
{ name: "Priya", dept: "ECE" }
{ name: "Suresh", dept: "IT" }
{ name: "Vijay", dept: "ECE" }

Explanation

$nin      → Not In
_id: 0    → Hide _id field
name: 1   → Show name field
dept: 1   → Show dept field

7. Find total revenue per category using $group and $sum on a computed field (price × sold)
db.products.aggregate([
{
    $group: {
        _id: "$category",
        totalRevenue: {
            $sum: {
                $multiply: ["$price", "$sold"]
            }
        }
    }
}
])
Explanation
$multiply → price × sold
$sum      → adds revenue of all products
$group    → groups by category
Expected Result
{
  "_id": "Electronics",
  "totalRevenue": 14585000
}
{
  "_id": "Furniture",
  "totalRevenue": 612000
}
{
  "_id": "Books",
  "totalRevenue": 629000
}

8. Use aggregation to find total number of students and average marks per department
db.students.aggregate([
{
    $group: {
        _id: "$dept",
        totalStudents: { $sum: 1 },
        averageMarks: { $avg: "$marks" }
    }
}
])
